### `Exchanger`

```markdown
# Currency Exchanger
```
REST API for currency exchange. Frontend - [Exchanger-Frontend](https://github.com/maff1337/exchanger-frontend)

## Stack

- `Python 3.13+`
- `SQLite`
- `http.server`
- `uv`

## Features

- Currency management
- Exchange rate management
- Currency conversion
- REST API
- CORS

## Run

```bash
uv sync
uv run exchanger
```

The API uses SQLite for data persistence.
